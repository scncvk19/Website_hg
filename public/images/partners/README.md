Die beiden PNG-Dateien wurden über den Workflow importiert; das Netwrix-SVG stammt direkt aus dem offiziellen Herstellerrepository netwrix/docs (`static/branding/Netwrix_Logo_Dark.svg`). Der vorherige JPEG-Import schlug fehl und wurde durch das Original-SVG ersetzt. Ohne Datei greift die Textdarstellung. Die historischen Nachweise bleiben unverändert.

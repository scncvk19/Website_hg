# Zertifikatsbilder

Microsoft/ITIL-Abzeichen und öffentlich dokumentierte historische Vorschaubilder: Quellen und Zielpfade in `lib/certificate-assets.json`. Der Import erfolgt mit `scripts/import-certificate-images.ps1`. Originaldateien, Nutzungsrechte und personenbezogene Angaben vor Commit bzw. Veröffentlichung prüfen. Die Vorschau verwendet bis dahin die öffentlichen Bildquellen mit no-referrer und einen neutralen Ersatz bei Ladefehlern.
